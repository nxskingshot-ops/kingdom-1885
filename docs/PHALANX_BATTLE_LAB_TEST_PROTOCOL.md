# PHALANX Battle Lab — agreed test protocol

Status: approved concept, not yet implemented. Date: 2026-10-14.

## Responsibilities
PHALANX designs controlled Kingshot marches according to research needs. The player/alliance executes the specified marches only after reviewing and approving them, and provides actual battle reports for analysis. No automated in-game actions.

## Before each test
Record test ID, question/hypothesis, exact hero lineup and order, skill levels, troop counts and ratio, rally leader and joiners, opponent/target, relevant buffs, conditions, baseline and predicted proxy metrics. Prefer low-cost and low-loss tests. Change one variable at a time where feasible.

## After each test
Record actual configuration, deviations, timestamp, screenshots/reports, damage/score/losses as applicable, confounders, and model-vs-observation comparison. Repeat uncertain tests; never infer win probability from an uncalibrated proxy.

## Rules
Do not change frozen app UI or production systems. No real-world spending, troop losses, or alliance-wide tests without explicit user approval. Keep reports identifiable by test ID and version. Preserve raw observations separately from interpretations. Implementation and test marches are future work.
