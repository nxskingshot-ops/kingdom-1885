The current Nexus App remains untouched. Nexus App 2.0 is developed separately as a parallel preview/test version.

The approved Nexus App 2.0 visual reference is binding. No unsolicited changes are allowed to:

The approved reference uses:
- premium dark-fantasy / military command-center aesthetic

- fine gold/blue borders

## Mobile / responsive behavior

- Portrait is the default mobile orientation.
- Landscape automatically expands into a wider command-center view.
- No function may require landscape.
- Landscape uses the fixed left sidebar.
- Portrait uses a top-right menu button opening a full-screen/overlay menu in the same navy/gold visual language.
- Mobile is the same design system, not a separate design.
- Cards stack/reflow.
- Head-to-Head uses a compact two-column top comparison with details stacked below.
- Tables use a hybrid mobile treatment: key columns visible, tap for details.
- Important cards use full width; smaller status cards may use two columns.
- Header begins large/atmospheric and collapses to a compact sticky header on scroll.
- No horizontal mobile chaos.
